# Word-Pop Battle Project Audit

## Relationship between the supplied files

- `index.html` is the newest build (June 1, 2026) and is now the default page.
  It adds mobile/PWA metadata, seven icons, richer fullscreen and touch handling,
  performance adaptation, and a passcode-protected one-player mode.
- `word-pop-battle.html` is the older image-based two-player edition. It uses
  descriptive asset names and has been preserved as `variants/asset-edition.html`.
- `word-pop-battle-standalone.html` is a lightweight alternative that generates
  its artwork as SVG data URLs at runtime. It has no external image dependency and
  has been preserved as `variants/standalone-edition.html`.
- The separate `word-pop-battle-site/` repository in Playground is not referenced
  by any supplied HTML file and was not copied.

## Game model

- Four sports: Swimming, Rock Climbing, Snorkeling, and SUP.
- Each sport produces three tasks: identify the sport, select its equipment, and
  select its safety rules. The complete match therefore contains 12 rounds.
- Each round starts with an 18-second timer.
- Two-player scoring awards 10 points for a correct pop, deducts 5 for a wrong
  pop without going below zero, and awards twice the remaining seconds as a
  lane-clear bonus.
- The current build adds one-player scoring: +15 correct, -12 wrong, and three
  times the remaining seconds as a clear bonus.
- Audio is synthesized with the Web Audio API; there are no audio files.
- The finish and one-player controls use the code `143`. This is a classroom
  control embedded in client code, not a security boundary.

## Technical checks and observations

- All three scripts compile successfully as JavaScript.
- No required DOM ID lookup is missing, and the pages have no duplicated live
  HTML IDs.
- There are no remote libraries, API calls, analytics, forms, databases,
  browser-storage calls, or server-side components.
- The current page includes a manifest but no service worker, so it has app
  metadata without an offline-cache layer.
- The current viewport disables user zoom, which can reduce accessibility for
  users who need magnification.
- The one-player result checks `score > 300`; a score of exactly 300 is treated
  as not beating the stated 300-point goal.
- The game relies on modern features including Map, Set, optional chaining,
  flatMap, Web Audio, requestAnimationFrame, and the Fullscreen API.
- The standalone edition repeats the SVG gradient ID `g` inside separately
  generated data images. Those IDs are isolated per image and do not conflict
  in the live document.

## Separation and transfer

- All three embedded stylesheets were moved into independent files under `css/`.
- All three embedded scripts were moved into independent files under `js/`.
- Current, legacy, and icon paths were rewritten for the new folder structure.
- Exactly 89 referenced image/icon files were copied; unrelated Playground files
  and `.DS_Store` metadata were excluded.
- Every copied binary was verified byte-for-byte with SHA-256.
